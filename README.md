# Aether Messenger

An experimental messenger with an iOS-inspired design and ideas from Discord and Telegram.

## Status
🚧 Work in progress. Some features are unfinished or not working yet.

## Features (planned or in progress)
- Chat rooms and invites
- Voice call overlay and soundboard
- Peer-to-peer connection
- Encryption module
- AI assistant (Gemini)

## Tech
React, TypeScript, Vite, Firebase, Gemini API

## Run locally
1. Install [Node.js](https://nodejs.org)
2. `npm install`
3. Copy `env.example` to `.env.local` and add your `GEMINI_API_KEY`
4. `npm run dev`

## Known issues
- P2P connection is unstable
- Not all features are finished
